    🚀 Programación de Aplicaciones utilizando Frameworks

    Repositorio de la asignatura Programación de Aplicaciones utilizando Frameworks.

    📚 Código: CLM1042
    ⏱️ Duración: 80 horas
    👨‍🏫 Profesor: Francisco Alía
    🏫 CIFP Virgen de Gracia – Puertollano

    📖 Descripción

    En esta asignatura aprenderemos a desarrollar aplicaciones web modernas utilizando frameworks tanto de Back-End como de Front-End, además de trabajar aspectos fundamentales como el despliegue, el diseño de interfaces y las pruebas automatizadas.

    El objetivo será recorrer el ciclo completo de desarrollo de una aplicación:

    Back-End → API REST → Front-End → Interfaz → Testing → Despliegue

    🎯 Resultados de Aprendizaje

    RA Resultado de Aprendizaje
    RA1 Crear aplicaciones Back-End utilizando frameworks de servidor
    RA2 Crear aplicaciones Front-End utilizando frameworks de cliente
    RA3 Desplegar aplicaciones de cliente y servidor creadas con frameworks
    RA4 Modificar interfaces de usuario utilizando frameworks de diseño
    RA5 Crear baterías de pruebas mediante frameworks de testeo

    🛠️ Tecnologías

    Durante el curso trabajaremos principalmente con:

    🐍 Python

    Fundamentos del lenguaje y programación orientada a objetos.

    🌐 Django

    Desarrollo de aplicaciones Back-End y APIs REST.

    🍃 Spring Boot

    Desarrollo de aplicaciones Back-End con Java.

    🅰️ Angular

    Desarrollo de aplicaciones Front-End modernas.

    🐳 Docker

    Contenedores y despliegue de aplicaciones.

    🎨 Frameworks de interfaz

    Diseño y personalización de interfaces mediante librerías como PrimeNG.

    🧪 Testing

    Pruebas automatizadas utilizando pytest y JUnit.

    📚 Unidades

    Unidad 1 — Fundamentos de Python

    Bases del lenguaje y programación orientada a objetos.

    RA1 → 10 %

    Unidad 2 — Desarrollo de aplicaciones Back-End con Django

    Desarrollo de aplicaciones web utilizando Django, bases de datos y APIs REST.

    RA1 → 40 % · RA3 → 33 % · RA5 → 33 %

    Unidad 3 — Desarrollo y despliegue de aplicaciones Back-End con Spring Boot

    Creación de aplicaciones Back-End con Spring Boot y despliegue de aplicaciones.

    RA1 → 50 % · RA3 → 33 % · RA5 → 33 %

    Unidad 4 — Desarrollo y despliegue de aplicaciones Front-End con Angular

    Desarrollo del Front-End, diseño de interfaces y despliegue de aplicaciones cliente.

    RA3 → 34 % · RA4 → 100 % · RA5 → 34 %

    📊 Ponderación de los RA

    RA Peso
    RA1 – Back-End 35 %
    RA2 – Front-End 35 %
    RA3 – Despliegue 10 %
    RA4 – Interfaz de usuario 10 %
    RA5 – Testing 10 %

    🔄 Recuperación

    Los Resultados de Aprendizaje se evalúan de forma independiente.

    Si un alumno obtiene una calificación inferior a 5 en un RA, deberá recuperar únicamente ese RA pendiente mediante una prueba práctica en la primera convocatoria ordinaria.

    Si el RA continúa suspenso, tendrá una nueva oportunidad de recuperación en la segunda convocatoria ordinaria.

    🎯 No se recupera toda la asignatura: se recuperan únicamente los RA no superados.
